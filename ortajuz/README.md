# ortajuz.kz

Сопровождение информационных систем по SLA, аналитика и доработка.

**Эта папка — корень сайта.** Всё её содержимое заливается в корневую
директорию домена ortajuz.kz. Ничего собирать не нужно: ни Node, ни npm,
ни шага сборки.

## Как залить

Через панель хостинга или FTP скопируйте **содержимое** этой папки
(не саму папку) в корень домена — обычно это `public_html`, `www`
или `httpdocs`:

```
index.html
404.html
contacts.html
privacy.html
robots.txt
sitemap.xml
assets/
services/
```

Готовый архив можно собрать одной командой из корня репозитория:

```bash
./tools/package.sh     # создаст dist/ortajuz.zip
```

Распакуйте `dist/ortajuz.zip` прямо в корень домена — структура уже
правильная, без лишней вложенной папки.

## Перед заливкой

Обязательно замените заглушки в `assets/js/config.js` — телефон, почту,
адрес, реквизиты и приёмник заявок. Это единственный файл с контактами,
в HTML лезть не нужно.

Полный список — в [CONTENT-CHECKLIST.md](../CONTENT-CHECKLIST.md) в корне
репозитория.

## Настройка сервера

Страницу ошибок нужно указать явно, иначе хостинг покажет свою:

```nginx
error_page 404 /404.html;
```

Для Apache — в `.htaccess`:

```apache
ErrorDocument 404 /404.html
```

## Важно про правку файлов

Файлы `assets/css/core.css`, `assets/js/core.js`, `assets/js/i18n.js`
и `assets/js/i18n-common.js` — копии общего ядра из `../shared/`.
Правьте их **там**, потом выполните `./tools/sync-shared.sh` из корня
репозитория. Прямые правки здесь будут затёрты.

Остальное — `theme.css`, `config.js`, словари `i18n-*.js` и все HTML —
принадлежит только этому сайту, правится здесь.
