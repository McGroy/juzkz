# Фирменные материалы

Исходники логотипов. Не удалять: из них собраны SVG для сайтов.

```
ortajuz/
  orta_juz_logo_white.ai     исходник Illustrator, светлый вариант
  orta_juz_logo_white.pdf    он же в PDF
  orta_juz_logo_black.ai     исходник Illustrator, тёмный вариант
  orta_juz_logo_black.pdf    он же в PDF
```

## Что из них сделано

Векторы переведены в SVG без изменения начертания и лежат в
`ortajuz/assets/img/`:

| Файл | Что это | Где используется |
|---|---|---|
| `logo.svg` | Полный логотип, белый | Шапка и подвал сайта |
| `logo-black.svg` | Полный логотип, чёрный | Для светлого фона, на сайте пока не используется |
| `mark.svg` | Только розетка, белая | Запас для компактных мест |
| `mark-black.svg` | Только розетка, чёрная | То же для светлого фона |
| `favicon.svg` | Розетка в скруглённом квадрате | Иконка вкладки |
| `og.svg` | Превью для соцсетей | Ссылки на сайт в мессенджерах |

### Почему у фавикона 12 лучей вместо 36

Полная розетка на 16×16 пикселях сливается в серое пятно: лучи тоньше
одного пикселя. В фавиконе оставлен каждый третий луч — знак остаётся
узнаваемым до 16px. Это единственное место, где геометрия упрощена.

### Как перекрасить логотип

Цвет задан атрибутом `fill` в корне SVG. Например, чтобы сделать логотип
золотым под акцент сайта, в `logo.svg` замените `fill="#ffffff"`
на `fill="#E0A82E"`. Начертание при этом не меняется.
